## 2. 盘前早报按市场拆卡 + 多策略共振【重要】卡

**动机**：原早报是单张卡 + 5 行上限，动量 7 条 BUY 占满名额把 MACD/RSI/布林挤没了。

**设计**（spec：`specs/2026-07-05-premarket-market-split-cards-design.md`）：
- 单张早报拆成 **美股组 / 港股组 / 韩股组** 多张卡（美股优先，跳过空卡），不限行。
- 市场归类用 `international_tickers`（HKD→港股、KRW→韩股，其余→美股）。
- 每张市场卡内部按策略分小节（动量/MACD/RSI/布林），空小节跳过。
- 新增 🔥**【重要】多策略共振卡**：同一标的被 ≥2 个策略**同向**命中时单列，排最前推送；
  共振标的仍保留在各策略小节。
- 实现：新增纯函数 `notifier/cards.py::premarket_cards()`，删除旧的 `PREMARKET_REPORT_LIMIT`/
  `_select_report_rows`。

## 3. 动量名次修正（组内名次）

**Bug**：`reason` 里名次是全局动量名次却配分组标签，自相矛盾（"美股个股组第3"、韩股组唯一
标的却写"第2"）。

**修法**：名次改为**组内名次**（每组从第1起）：港股组第1、韩股组第1、美股个股组第1/2/3、
美股ETF组第1/2。卡片动量小节仍按动量降序展示。**只是显示修正，不影响选股与权重。**

## 4. 趋势持有闸门 + 防御切换（降回撤）

**目标**：动量组合夏普 2.5~2.9 已很好，痛点是**最大回撤 30~44%**（永远满仓高 beta 半导体）。

**设计**（spec：`specs/2026-07-05-trend-hold-gate-design.md`，计划：
`plans/2026-07-05-trend-gate-phase-ab.md`）：动量选出标的后叠一道绝对趋势闸门，趋势失效的
仓位切防御 sleeve（BIL/TLT/GLD 按绝对动量选最强，BIL 即现金地板）。

- 实现：纯函数 `strategies/trend_gate.py`——状态机（FLAT/LONG 迟滞，双失效 EXIT/单失效 WARN），
  逐周五重放推导 state（无未来函数），`apply_trend_gate` 做防御切换。
- 调仓：慢进快出——动量选股月度、趋势/退出检查设计上支持周度。

### 回测结论（go/no-go，控制组对照，2016 至今）

报告：`research/reports/trend_gate_from20160101_run20260705.md`

| 方案 | 年化% | Sharpe | 最大回撤% |
|---|---|---|---|
| 基线（无闸门） | 56.8 | 1.99 | 44.5 |
| **仅200线+防御（采用）** | 56.6 | **2.08** | **29.5** |
| 仅绝对动量+防御 | 46.4 | 1.91 | 28.8 |
| 完整闸门+防御 | 53.6 | 2.01 | 33.9 |
| buy&hold SPY | 15.2 | 1.04 | 33.7 |

**关键发现**：
- **"仅200日线+防御"最优**：回撤 44.5%→29.5%（降 15pp），年化几乎不变，夏普升到 2.08。
- 原 spec 的"完整闸门"（加绝对动量/相对强弱）**反而更差**（过度保守，动量选股本身已挑相对
  强势票，再叠一层冗余）。
- buffer 不敏感；周度退出相比月度无额外增益（月度换手还更低，故未加独立周五 job）。
- **据此上线用 `use_mom=false` 的赢家配置，而非照搬 spec**——这正是控制组回测的价值。

**上线状态**：`settings.yaml` 的 `trend_gate.enabled=true`，`run_premarket` 已接入，真机验证
（当前所有票趋势健康 LONG，无防御切换；防御逻辑由单测覆盖）。

## 5. 卖出价：从错误 → 止盈/止损两个价

经过三轮迭代，最终区分**止盈（高于现价）**与**止损（低于现价）**：

1. **v1（错）**：`sell_ref = SMA200×(1-buffer)`。对暴涨的半导体离现价 30~61%，毫无心理预期
   价值（现价是 200 均线 2 倍多）。根因：200 线适合当"是否持有"的慢速闸门，不适合当卖出价。
2. **v2**：改 ATR 吊灯移动止损（近22日高−3×ATR），贴价 −3%~−9%。但概念仍混淆——这是止损
   不是止盈。
3. **v3（最终）**：按用户澄清分两个价：
   - **止盈目标**（高于现价）：波动率期望位 `现价×(1+日波动×√20)`，未来约1个月 1σ 上沿。
     高波动股目标自适应更高（半导体给到 +15%~+33%）。定位为**参考心理位**，非到点即卖
     （动量真正离场靠止损/闸门，避免卖在半山腰——业界"让利润奔跑"）。
   - **止损价**（低于现价）：ATR 吊灯移动止损。
   - **卖出信号不给价**（符合用户要求）；覆盖所有 BUY 信号（含 MACD/RSI/布林）。
   - 止损已在现价上方（急跌破位）标注 `⚠破位`。
- 实现：`strategies/indicators.py`（`atr`/`chandelier_stop`/`expected_move_target`），
  引擎 `_attach_exit_prices`，卡片双列【止盈目标】【止损价】。

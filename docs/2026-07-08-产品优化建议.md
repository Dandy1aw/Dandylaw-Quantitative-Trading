# quant-signal 产品优化建议：对照主流量化实践的差距与路线

日期：2026-07-08 · 针对用户四个核心诉求逐一对照：
**① 哪些股票有价值 · ② 什么价格买入 · ③ 什么价格卖出（盈利）· ④ 仓位控制**

写作原则：只基于已核实的代码现状与已跑出的回测证据，不吹不黑。

---

## 〇、先说清楚当前系统的真实定位

现在的 quant-signal 是一台**价格动量轮动器 + 技术信号播报器**：
60 日相对强弱选强者 → 200 日线闸门砍尾部 → 吊灯止损/波动率止盈给参考价 → 飞书播报。
回测（2016 至今，32 只池）证明这条主线是有效的，且已知它的钱主要来自右尾少数大牛股。

它**不做**的事：估值判断（"有价值"）、入场择价、执行跟踪、组合级风险。
这正好对应你的四个诉求的缺口。下面逐一对照主流做法。

---

## 一、"哪些股票有价值" —— 现状：只有动量，没有"价值"

| | 现状 | 主流做法 |
|---|---|---|
| 选股因子 | 仅 60 日价格动量 1 个因子 | 多因子打分：**价值**(PE/PB/FCF yield)、**质量**(ROE/毛利率/负债率)、**动量**、低波动，加权合成 |
| 池子来源 | 手工挑的 32 只（回测报告已证实有严重幸存者偏差） | 全市场按流动性/市值初筛 → 因子排名构造池子 |
| 基本面 | UZI 深度分析仅展示、不进决策 | 因子直接参与打分与否决 |

**差距本质**：动量回答"谁最近强"，回答不了"谁贵谁便宜"。当动量失效（风格切换）时系统没有第二个视角。

**建议（P5，做但不急）**：
- v1 用 yfinance 免费基本面字段（PE/PB/ROE/毛利/净债务）做**质量否决器**而非选股器：
  动量选出的票若质量分垫底（如 ROE<0 且高负债），卡片标注 ⚠质量差，不改选股。
  理由：先当"提示层"上线观察，有绩效数据后再决定是否进决策——避免拍脑袋改已回测的主线。
- 不建议自建全市场扫描（数据成本/复杂度陡增），维持"自选池+校验"模式，但把
  **池子成分定期审视**做成产品动作（季度提醒：哪些票已连续 N 月垫底建议移出）。

## 二、"什么价格买入合适" —— 现状：只说"今天买"，不说"多少钱买"

| | 现状 | 主流做法 |
|---|---|---|
| 入场价 | 参考价=昨收，暗示开盘市价买 | **入场区间**：突破确认价 / 回踩支撑带（如 10日均线±0.5×ATR）分批限价 |
| 追高保护 | 无（动量票常在急涨后出信号） | 过度伸展过滤：距 20 日均线 > k×ATR 时标"等回调" |

**建议（P3）**：给每条 BUY 信号算一个**建议买入带 [entry_low, entry_high]**：
- `entry_high` = 现价（愿意追就现价）
- `entry_low` = max(10 日均线, 现价 − 1×ATR14)（常见回踩位）
- 若现价距 20 日均线 > 2.5×ATR：卡片标注 `⚠短线过热,建议等回踩带`。
纯展示层、不改信号生成，风险极小；实现只用已有的 indicators.py 语汇。

## 三、"什么价格卖出（能让我盈利）" —— 现状：最完整的一块，缺的是闭环

已有：吊灯止损（低于现价）+ 波动率止盈参考位（高于现价）+ 200 线闸门 + 动量轮出。
且回测证明过：对这套组合**加更紧的止损是负贡献**（年化 -8pp），当前"松止损+让利润跑"是对的。

**真正缺的不是卖出价，是执行闭环**：系统不知道你按信号买了没有、卖了没有、赚没赚。
→ 见第五节"绩效闭环"，那才是"能让我盈利"的度量基础。

**建议（小改，随 P3 一起）**：SELL/轮出信号在卡片里带上"持有期收益"（信号价 vs 当初 BUY 信号价），
让每次卖出提示自带盈亏语境。

## 四、"仓位控制" —— 现状：等权 1/n，有一个真实的洞

| | 现状 | 主流做法 |
|---|---|---|
| 单票权重 | 等权 1/n + FLAT 切防御 | 波动率目标/风险平价、**单票风险上限**、分数 Kelly |
| 杠杆产品 | **SNXX/MUU/RAM 三只 2x ETF 与 SPY 等权同仓**——同样一份仓位，风险是 SPY 的 4~6 倍 | 按风险等价折算仓位（杠杆 ETF 权重÷实际波动倍数） |
| 集中度 | 无约束（半导体链 MU/SMH/SNXX/RAM/MUU/TSM/AMD… 名义分散实为一注） | 行业/相关簇上限（如单一主题 ≤40%） |
| 组合级 | 无 | 组合波动目标、回撤触发减仓 |

**重要的诚实前提**：全组合"反波动率仓位"我们回测过是**负贡献**（年化 -7.6pp 换回撤 -1.6pp，夏普还降）。
所以这里提的不是那个，而是两个更窄、未被那次回测否定的东西：
1. **杠杆 ETF 风险等价折算**——只对 2x 产品把权重除以其相对基准的实际波动倍数，其余票不动；
2. **相关簇集中度提示**——展示层，标出"当前持仓 N% 集中在存储/半导体一条链上"。

**建议（P1，最优先）**：先回测验证 #1（等权 vs 杠杆折算），有效才上线；#2 直接做（纯展示）。

## 五、主流有而我们完全没有的：绩效闭环（P2，价值最高的缺失）

**现状**：信号推出去就结束了。没人知道上月 40 条 BUY 里多少条赚钱、四个策略哪个在贡献、
哪个在磨损。"能让我盈利"目前无法被验证，只能感觉。

**主流做法**：每条信号自动记虚拟成交（信号价买入、按自家止损/轮出规则平仓）→
**策略级虚拟账本** → 周报卡片：每策略近 4 周信号数/胜率/平均盈亏/累计虚拟收益 vs SPY。

**这是把系统从"播报器"变成"可自我检验的引擎"的关键一步**，也直接回答"哪个策略值得信"。
实现完全基于已有 ledger（signals 表已存价格/方向/策略），加一张虚拟持仓表 + 周日结算 job + 周报卡。

## 六、其他值得做的（按性价比）

- **财报日风险提示（P4，便宜且救命）**：动量票财报暴雷是最大单日风险。yfinance 有 earnings 日历，
  BUY 信号若 7 天内有财报 → 卡片标 `⚠N天后财报`。
- **组合快照卡（随 P1 的 #2）**：每周一张——当前持仓、各票权重、行业集中度、距止损距离。
- **市场状态卡（后续）**：SPY/QQQ 相对 200 线 + 全池动量中位数，一行字的 risk-on/off 语境。

## 七、执行顺序（结论）

| 优先级 | 项 | 类型 | 验收 |
|---|---|---|---|
| **P1** | 杠杆 ETF 风险等价仓位（先回测）+ 相关簇集中度提示 | 决策层(需回测背书)+展示层 | 回测报告 + 卡片 |
| **P2** | 信号绩效闭环：虚拟账本 + 每周策略绩效报告 | 基础设施 | 周报卡真实推送 |
| **P3** | 买入带 [entry_low, entry_high] + 过热标注 + 卖出带持有期盈亏 | 展示层 | 卡片字段 |
| **P4** | 财报日提醒 | 展示层 | 卡片标注 |
| **P5** | 质量因子否决器（先提示不决策） | 提示层 | 卡片标注 |
| 后续 | 市场状态卡 / 池子季度审视提醒 / 全市场扫描(不建议现在) | - | - |

原则重申：**凡动决策(选股/仓位)必先回测背书；展示层直接上**。每项独立提交、测试全绿。

# 策略优化实验计划（S1-S6）

日期：2026-07-08。承接《产品优化建议》(P1-P5 已完成)，本轮聚焦**策略/验证层**。
原则不变：**凡动决策必先回测背书；负结果照实记录并保留脚本**。

## 已证伪、不再重复的方向（本项目自己的回测证据）

更紧止损(年化-8pp)、完整双动量闸门、个股反波动率仓位(-7.6pp换-1.6pp回撤)、
周度退出(无增益)。这些是资产：说明"松止损+让利润跑+慢闸门"内核接近局部最优。

## 实验清单（按执行顺序）

### S1 · 纳指100对照实验 —— 回答"alpha 是否真实存在"（最优先）
- **假设**：若动量策略逻辑真有效，在**没有手工挑过赢家**的池子上也应显著跑赢基准。
- **方法**：同一策略(60日动量, 全局 top5, 同成交额门槛)跑在纳指100近似成分池(~70+只
  大市值流动票) vs 自选池 vs SPY/QQQ 买入持有，2016 至今与 2023 至今两个窗口。
- **诚实声明**：用**当前**成分仍含"入指数即幸存"偏差，非 point-in-time——它消除的是
  "手工挑赢家"偏差，结论只用于相对判断，绝对数字仍偏乐观。
- **判读**：对照池上仍大幅跑赢基准 → 策略逻辑可信，其他优化有意义；
  仅在自选池上赢 → 系统定位应改为"自选池择时器"，重心转向风控而非选股。

### S2 · 多周期动量集成 —— 信号层加固
- **假设**：60日是单点参数(我们扫描过 30/60/90/120 差异不小)，3/6/12个月(63/126/252日)
  动量合成打分可降低"选参运气"，回撤特性更稳。
- **方法**：composite = 三周期动量均值，与单 60日 对照回测(两个池子都跑)。
- **上线条件**：对照池与自选池**同时**不差于单周期(夏普/卡玛)，才改生产。

### S3 · 调仓时点运气量化 + 分批错峰
- **假设**：月末单一时点调仓含 rebalance timing luck；4 个错峰子组合可分散。
- **方法**：把月度调仓锚点分别设在第1/2/3/4周，看四个变体的年化离散度；
  再回测"4等份子组合各自错峰月调"的合成组合。
- **附注**：生产实际是"每日评估、排名变化即换"，与回测的月末口径本就有差异——
  报告需一并量化这个差异（每日评估版 vs 月末版）。

### S4 · 组合级波动率目标（与已证伪的"个股反波动率"不同）
- **假设**：个股反波动率改变**分配**（证伪）；组合级 vol target 只控**总闸**——
  组合近20日年化波动超过目标(如30%)时整体等比降仓、余下现金，可能便宜地砍尾部。
- **方法**：在 ma_only+防御 基础上叠加，目标扫 {25%, 30%, 35%}。
- **上线条件**：回撤/卡玛改善且年化损失可接受，否则记负结果。

### S5 · PEAD 财报后漂移提示（展示层）
- yfinance earnings_dates 有 EPS 实际 vs 预期；财报后 BUY 标的若上季**超预期**，
  卡片加"财报超预期"正向语境（反之提示拖累）。不进决策。

### S6 · 双源数据校验（数据质量，生产功能）
- 每日 maintenance 时对 universe 抽样对比 Alpaca(IEX) vs yfinance 收盘价，
  偏差 >0.5% 的标的发告警卡——IEX 只含 ~2-3% 成交量，动量输入需要这道体检。

## 实验结论汇总（2026-07-08 全部完成）

| 实验 | 裁决 | 关键数字/发现 |
|---|---|---|
| S1 对照池 | **结论翻转性发现** | 严格同口径后：对照池 2016 窗口仅弱胜 QQQ(夏普1.18vs1.14)，2023 窗口全面跑输(0.78vs1.45)。**超额主要来自挑票，系统诚实定位=自选池的择时与风控器** |
| S2 多周期集成 | 不上线(能力保留) | 对照池更稳(0.78→1.06,换手减半)但自选池更差(2.34→1.82)——60日参数部分拟合了池子性格 |
| S3 时点运气 | 不上产(方法论产出) | 同策略只挪调仓日年化差 3.8~5.6pp → **回测读数规则:<5pp差异不算数**；生产的每日评估口径无劣化 |
| S4 组合vol目标 | 不上线(负结果) | 夏普升但卡玛降(1.75→1.58)、年化-8~13pp。"降波动"三连阴(个股反波/紧止损/vol目标)——慢闸门+让利润跑已是帕累托前沿 |
| S5 PEAD提示 | ✅ 已上线 | 近30天财报超预期/不及预期注入BUY卡片语境 |
| S6 双源体检 | ✅ 已上线 | 每日03:30 ET对比 IEX vs yfinance 收盘，偏差>0.5%告警 |

**全轮最大收获**：S1 的定位修正 + S3 的噪声带读数规则。四个"聪明的策略改法"全部
被证据否决，而两个朴素的数据/提示功能上线了——这正是控制组回测存在的意义。

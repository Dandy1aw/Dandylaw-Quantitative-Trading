# 恐慌指数定投提醒设计

## 1. 目标与边界

新增一个独立的日级“恐慌指数定投提醒”模块，使用最近完整美股交易日的 VIX、VXN、SPY 和 QQQM 日线，在北京时间工作日上午生成并推送纪律化的恐慌加仓建议。

该模块只提供定投倍数提醒，不接入订单执行，不自动下单，也不改变已有常规定投计划。报告中的 `0×` 表示本次不进行恐慌加仓，而不是取消用户原有定投。

首版目标：

- 展示 VIX、VXN 最新完整收盘值、单日变化、MA20 和 MA60。
- 展示 SPY、QQQM 的 1、5、20 个交易日变化。
- 按明确、可审计的规则分别给出 SPY 和 QQQM 的推荐投入倍数。
- 生成 60 交易日双面板波动图并接入飞书卡片。
- 支持定时推送、手动重发、规则查询和历史结果审计。

## 2. 推送时序与交易日语义

定时任务固定使用 `Asia/Shanghai` 时区，在北京时间周一至周五 09:30 执行：

- 周一使用上周五或此前最近一个完整美股交易日的收盘数据。
- 周二至周五使用最近一个完整美股交易日的收盘数据。
- 周六、周日不执行定时推送。
- 美股休市后若最新完整交易日已正式推送，则不重复推送旧报告。
- 以美股交易日作为正式报告唯一键；服务重启、任务补跑和误触发不得重复发送。

任务运行时通过美股交易日历确定最近完整交易日，不依赖简单的“北京时间减一天”。夏令时与冬令时不改变北京时间 09:30 的调度时刻。

## 3. 数据源与数据质量

首版统一通过现有 `YFinanceSource` 获取以下自动复权日线：

- `^VIX`：标普 500 波动率指数。
- `^VXN`：纳斯达克 100 波动率指数。
- `SPY`：标普 500 定投观察标的。
- `QQQM`：纳斯达克 100 定投观察标的。

一次抓取至少覆盖 100 个自然日，并满足：

1. 四个标的均包含目标交易日。
2. 四个标的目标日期完全一致。
3. VIX 与 VXN 各自至少有 60 个截至目标日的有效交易日。
4. 所需收盘值必须是有限正数。
5. MA20、MA60 必须由完整的 20、60 个有效交易日计算。
6. SPY、QQQM 必须具备计算 1、5、20 交易日变化所需的历史收盘。

任何关键条件不满足时均失败关闭：不沿用旧数值，不猜测缺失数据，不给出投入倍数。系统保存失败运行及错误原因，并通过飞书发送一次“数据不完整，今日暂停给出推荐”的降级通知。

## 4. 指标计算

### 4.1 恐慌指数

对 VIX、VXN 分别计算：

- 最新完整交易日收盘值。
- 相对前一交易日的百分比变化。
- 最近 20 个交易日收盘简单移动平均 MA20。
- 最近 60 个交易日收盘简单移动平均 MA60。
- 当前值相对 MA20、MA60 的百分比偏离。

均线只用于解释恐慌环境，不直接降低或提高投入倍数：

- 高于 MA20：短期恐慌升温。
- 同时高于 MA20 与 MA60：恐慌趋势确认。
- 同时低于 MA20 与 MA60：恐慌回落。
- 其他情况：恐慌环境分化。

### 4.2 ETF 近期变化

SPY 与 QQQM 分别计算：

- 1 日变化：目标日收盘相对前一交易日收盘。
- 5 日变化：目标日收盘相对 5 个交易日前收盘。
- 20 日变化：目标日收盘相对 20 个交易日前收盘。

## 5. 投入倍数规则

### 5.1 SPY 基础倍数

| VIX 收盘区间 | 基础倍数 |
|---|---:|
| `< 25` | `0×` |
| `25 ≤ VIX < 30` | `1×` |
| `30 ≤ VIX < 40` | `1.5×` |
| `40 ≤ VIX < 50` | `2×` |
| `VIX ≥ 50` | `3×` |

### 5.2 QQQM 基础倍数

| VXN 收盘区间 | 基础倍数 |
|---|---:|
| `< 35` | `0×` |
| `35 ≤ VXN < 40` | `1×` |
| `40 ≤ VXN < 50` | `1.5×` |
| `50 ≤ VXN < 60` | `2×` |
| `VXN ≥ 60` | `3×` |

### 5.3 回撤加成

只有恐慌指数已经达到首档、基础倍数大于 `0×` 时，ETF 回撤才可增加倍数：

- SPY 近 5 日 `≤ -3%`，或近 20 日 `≤ -5%`：增加 `0.5×`。
- QQQM 近 5 日 `≤ -4%`，或近 20 日 `≤ -7%`：增加 `0.5×`。
- 同一标的即使两个回撤条件同时满足，也只增加一次 `0.5×`。
- 最终倍数封顶 `3×`。
- 恐慌指数未达到首档时，ETF 普通回调不能单独触发恐慌加仓，最终仍为 `0×`。

正式结果必须同时保存基础倍数、回撤加成、最终倍数和人类可读的触发原因，禁止只保存最终数字。

## 6. 飞书卡片与图表

### 6.1 60 交易日波动图

每天生成一张静态 PNG，包含两个纵向面板：

- 上图：VIX 收盘线、MA20、MA60、固定阈值线 25。
- 下图：VXN 收盘线、MA20、MA60、固定阈值线 35。
- 两个面板均展示最近 60 个交易日。
- 最新点标注日期、指数值和对应基础倍数档位。
- 阈值线与均线在图例中明确区分，图中不叠加 SPY/QQQM，避免信息过载。

图表生成与发送失败不得影响文字建议：图片上传成功时嵌入完整卡片；图片生成或上传失败时发送同一份完整文字卡片并记录降级原因。

### 6.2 文字内容

卡片标题包含目标美股交易日，例如“恐慌指数定投观察｜08/14 收盘”。正文包含：

1. 数据日期、生成时间和数据源。
2. SPY/VIX：VIX 当前值、日变化、MA20、MA60、均线位置，SPY 1/5/20 日变化，基础倍数、回撤加成、最终倍数和原因。
3. QQQM/VXN：同结构展示 VXN 与 QQQM。
4. 当前完整阈值规则的简明摘要。
5. “仅为纪律化定投提醒，不自动下单”的边界说明。

## 7. 持久化与幂等

新增独立历史表保存每次运行与正式报告，字段至少覆盖：

- 目标美股交易日、生成时间、状态和错误原因。
- 四个标的的数据源与数据完整性信息。
- VIX/VXN 收盘、日变化、MA20、MA60、均线偏离。
- SPY/QQQM 收盘及 1/5/20 日变化。
- 两个标的的基础倍数、回撤加成、最终倍数和原因。
- 图表生成状态、飞书发送状态及正式推送时间。

同一目标交易日只有一份正式计算结果。失败运行可被后续成功补跑替代，但 COMPLETE 结果不能被失败结果降级。定时推送通过交易日和发送状态实现幂等。

## 8. 飞书机器人指令

新增两个只读指令：

- `定投`：重发最新一份已完成报告，不重新抓取行情。
- `定投规则`：展示 VIX/VXN 基础倍数、SPY/QQQM 回撤加成、封顶规则及 `0×` 的含义。

群聊可以查询公开市场数据和规则；功能不展示账户余额、持仓或具体金额。

## 9. 组件边界

实现拆分为以下独立组件：

1. 纯规则模块：输入四组时间序列，输出指标、倍数与原因，无 IO。
2. 日级流水线：选择目标交易日、拉取数据、执行质量校验、调用规则、持久化结果。
3. 图表生成器：只接收已验证结果并输出 PNG 字节或文件。
4. 飞书卡片构建器：根据正式结果生成完整文字卡片，可选嵌入图片。
5. 通知媒体上传：扩展现有飞书通知器以支持图片上传；保留文字降级。
6. 调度任务：北京时间工作日 09:30 运行，使用交易日幂等。
7. 机器人查询：只读取最新 COMPLETE 结果或静态规则。

该模块不依赖执行计划、持仓导入或交易订单组件。

## 10. 测试与验收

### 单元测试

- VIX 边界：25、30、40、50。
- VXN 边界：35、40、50、60。
- SPY/QQQM 的 5 日、20 日回撤边界。
- 两个回撤条件同时成立时只增加 `0.5×`。
- 基础倍数为零时不允许回撤单独加码。
- 最终倍数始终不超过 `3×`。
- MA20、MA60 和 1/5/20 日变化的交易日索引计算正确。

### 时间与质量测试

- 周一北京时间 09:30 选择上周五或此前最近完整交易日。
- 周二至周五选择最近完整交易日。
- 美股休市后不重复发送已推送交易日。
- 日期错位、历史不足、NaN、无穷值、非正数均失败关闭。
- COMPLETE 结果不能被 FAILED 运行覆盖。

### 图表与通知测试

- PNG 包含两个面板、60 个交易日、MA20、MA60 和固定阈值线。
- 图片生成失败或上传失败时仍发送完整文字卡片。
- 卡片显示目标日期、全部指标、规则拆解和最终倍数。
- `定投` 与 `定投规则` 返回已存储且一致的内容。

### 端到端验收

1. 使用真实 `^VIX、^VXN、SPY、QQQM` 日线和隔离数据库运行完整流水线。
2. 用录制通知器验证数据抓取、规则、落库、图表与机器人查询。
3. 在生产调度器停机窗口内对生产数据库执行一次真实流水线。
4. 发送一张真实飞书卡片，验证图片与文字降级路径。
5. 重启生产服务，确认 `fear_dca_reminder` 任务以 `Asia/Shanghai` 周一至周五 09:30 注册，stderr 无新增错误。

## 11. 非目标

- 不提供具体投入金额。
- 不连接券商下单接口。
- 不根据账户余额或当前持仓调整倍数。
- 不做盘中 VIX/VXN 追踪或重复告警。
- 不在首版加入历史回测优化、机器学习或动态百分位阈值。
